# Praxis

## Overview

Praxis is Duta Integra's AI-powered business process automation platform. It handles workflow routing, approval chains, document processing, and task orchestration — with human oversight on critical decisions.

## Key Features

- **Workflow Routing** — Intelligent task assignment based on workload and skill
- **Approval Chains** — Multi-level approval with escalation logic
- **Document Processing** — OCR, data extraction, auto-filing
- **Task Orchestration** — Cross-department task coordination
- **Process Mining** — Discover bottlenecks and optimize workflows
- **Compliance Tracking** — Automated audit trails and policy checks

## How It Works

1. **Map** — AI maps your existing processes and workflows
2. **Design** — Create automation rules with drag-and-drop
3. **Execute** — AI routes tasks, collects approvals, processes docs
4. **Optimize** — AI learns and suggests process improvements
