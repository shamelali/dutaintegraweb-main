# Sensai

## Overview

Sensai is Duta Integra's AI-powered intelligent learning systems platform. It provides personalized training, skill assessments, knowledge management, and adaptive learning paths — with human oversight on learning objectives.

## Key Features

- **Skill Assessments** — AI evaluates current competency levels
- **Adaptive Learning** — Personalized training paths per employee
- **Knowledge Base** — AI-curated company knowledge repository
- **Progress Tracking** — Real-time learning analytics and reporting
- **Content Curation** — AI selects relevant training materials
- **Certification Management** — Track and automate compliance training

## How It Works

1. **Assess** — AI evaluates your team's current skills and gaps
2. **Design** — Create personalized learning paths per role
3. **Deliver** — AI delivers training at the right pace and time
4. **Measure** — Track progress and impact on performance

## Use Cases

- Employee onboarding training
- Compliance certification tracking
- Technical skill development
- Leadership development programs

## Technical Details

- Supports SCORM, xAPI, and custom content formats
- PDPA-compliant employee data handling
- Integration with HR systems
- Mobile-friendly learning delivery
