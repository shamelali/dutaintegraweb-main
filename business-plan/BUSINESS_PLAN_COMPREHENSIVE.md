Existing vendors force them to choose: hire a cheap IT shop with no AI skills, or a trendy AI agency with no IT support and no PDPA knowledge. **The Solution:** Duta Integra Solutions is an **AI-first Managed IT partner built for Malaysian SMEs**. We combine what others separate: Enterprise-grade AI systems + 24/7 Managed IT + Cloud + Security + PDPA + Sales Automation + Content & Ads — under **three simple monthly retainers, month-to-month, no lock-in**. Everything is built on our owned, zero-cost infrastructure (Vercel Edge ap-southeast-1 Singapore <40ms to MY + Neon Serverless PostgreSQL) so we pass savings to clients.

- **4 Live Products:** Leish (beauty marketplace, 70% enquiry automation), Eastelpro (WiFi marketing & SIM platform, 99.9% uptime), AGMX (Malaysia's first AI-powered Cooperative AGM OS, 4-agent Governance Copilot), DutaConnect (community platform for Indonesians in MY - launching)
- **3 MRR Retainers:** Foundation RM2k, Growth RM5.3k (most chosen), AI Partner RM8.3k+
- **1 Entry Product:** Business Website RM2.5k (Merdeka RM775) -> natural bridge to retainers
- **Custom Admin Dashboard:** Lead pipeline with WhatsApp 1-click action, CSV export, AI Token Cost-Cap safeguard, RBAC (admin/staff/client), HttpOnly auth

**Traction:**
- Founded 2021 Cyberjaya, 100% Malaysian-owned, bootstrapped
- 5+ client projects shipped, 3 active retainers
- Stack proven: Vercel Hobby Tier + Neon Free Tier = RM0 infra cost at start, scales to paid only at growth
- PDPA-aware delivery, free audit, proposal in 3 working days

**Market Opportunity:**
- TAM: 1.17M SMEs x RM2k-8.3k MRR = RM28B+ annual potential in MY alone

### 5. MARKET ANALYSIS

**5.1 Malaysian SME Landscape (2024-2026)**
- Total SMEs: 1,173,601 (DOSM 2023) = 97.4% of business establishments
- Contribution: 38.2% GDP, 48% employment
- Digital Adoption: Only 28% have basic website, 12% use CRM, 5% use AI (MDEC Digital Adoption Survey)
- Government Push: RM1B+ in grants (MDEC MD2, SME Corp Digitalization Grant up to RM5k, Geran Digital PMKS Madani)
- Pain: 60% SMEs cite "lack of reliable IT support" and "cost of tech" as top barriers

**5.2 TAM / SAM / SOM**

- **TAM (Total Addressable Market):** All MY SMEs needing IT + AI
  - 1.17M SMEs * avg RM3k/mo (blended) * 12 = RM42.12B/year
  - Even conservative RM2k/mo * 12 * 1.17M = RM28.08B/year

- **SAM (Serviceable Available Market):** SMEs in Klang Valley, Selangor, Perak, Johor, Penang who are digital-aware, 10-100 staff, RM500k+ revenue
  - Estimated 100,000 businesses
  - 100k * RM3k * 12 = RM3.6B/year

- **SOM (Serviceable Obtainable Market):**
  - Year 1: 30 retainers = RM1.49M ARR = 0.04% SAM
  - Year 2: 60 retainers = RM3M ARR = 0.08% SAM
  - Year 3: 100 retainers + 3 SaaS spin-offs = RM5M+ ARR = 0.14% SAM
  - Very conservative, achievable via referrals and Merdeka campaigns

**5.3 Market Trends Favoring Us**
1.  **PDPA Enforcement Tightening:** PDPA 2010 amendments 2024 increase fines up to RM1M. SMEs scared, need PDPA audit - we offer it in Foundation.
2.  **AI Hype to AI ROI:** 2023 hype, 2024-2026 SMEs want practical AI (chatbot that reduces enquiries, not fancy demo). Our Leish 70% case study resonates.
3.  **WhatsApp Economy:** MY SMEs run on WhatsApp. Our 1-click WhatsApp lead action and WhatsApp chatbots are native.
4.  **Serverless Cost Advantage:** Vercel + Neon free tier lets us offer RM0 infra cost to start, vs competitors charging RM500/mo hosting. We pass savings.
5.  **Cooperative Digitalization:** 15,000+ cooperatives in MY under SKM, many need AGM digitalization (Akta Koperasi 1993). AGMX is first mover.

**5.4 Market Segmentation**
- **Traditional Brick-and-Mortar (50%):** Retail, F&B, beauty salons, workshops. Pain: no IT, leads lost. Pitch: Zero Maintenance, Local Speed, WhatsApp-first. Entry: Business Website RM775 -> Website Care -> Foundation.
- **Fast-Paced Startups (30%):** E-commerce, tech services, modern services. Pain: scaling, breaking prod, tight budget. Pitch: Git-like DB branching, rapid iteration, RM0 infra. Entry: Growth.

### 10. TECHNOLOGY STACK & INFRASTRUCTURE (Zero-Cost Blueprint)

**10.1 Philosophy**
We practice what we preach: enterprise-grade but cost-efficient. Our stack is serverless, edge-first, and starts at RM0.

**10.2 Stack by Project Type**

| Layer | WordPress Builds (for legacy SME) | Next.js / Custom Builds (Our Preferred, Owned) |
| :--- | :--- | :--- |

| Auth | WordPress auth | Custom Edge Middleware + HttpOnly cookie `di_admin_session` + RBAC |
| Email | - | Resend API |
| Bot Protection | - | Cloudflare Turnstile |
| SEO | Yoast | GA4, GSC, Meta Pixel, GTM, robots.txt, sitemap.xml with hreflang |

**10.3 Infrastructure Blueprint - Zero-Cost Setup**

- **Vercel Hobby Tier:** Global Edge CDN, Serverless Functions, Edge Middleware, Analytics. RM0.
- **Neon Free Tier:** Serverless PostgreSQL, WebSocket pooling, Git-like branching (instant DB branching for testing without touching prod). RM0.
- **Region:** `ap-southeast-1` (Singapore) - sub-40ms latency to Malaysia, better than US.
- **Monthly Cost at Start:** RM0. When we exceed free tier (e.g., 100k rows, 10k function invocations), we upgrade to Pro (~RM80-200/mo) but still far cheaper than traditional VPS RM500/mo that sleeps.
- **Value Prop to Client:** "Serverless architecture that sleeps when traffic idle - zero massive monthly server fees. Your website hosted on high-performance regional edge servers pointing directly to Malaysia."

**10.4 Security Architecture (Owned)**

- **Auth Flow:** Request to `/admin/*` -> Edge Middleware (`src/middleware.ts`) checks `di_admin_session` cookie -> If no cookie, redirect to `/admin/login` -> If cookie, crypto helper (`src/lib/auth.ts`) `getVerifiedAdmin()` cross-ref Neon DB -> Access granted
- **Features:** HttpOnly cookie (XSS-proof), Edge-level blocking (protects Neon DB limits), base64/buffer lightweight crypto, zero third-party auth cost (no Clerk)
- **Email API Hardening:** Hardcoded TO (hello@dutaintegra.my), origin check, rate limit 5/min, honeypot field, Turnstile verification, validation
- **Security Headers via vercel.json:** Strict-Transport-Security, X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy, etc.
- **Git Security:** `.gitignore` blocks *.pptx, *.pdf, .env, `.claude/`, `Web/` duplicate, `admin.html`. GitHub Actions security.yml runs gitleaks, npm audit, blocks sensitive commits.

**10.5 Database Schema (Owned)**

3 Core Tables (Drizzle ORM):
- `users`: id, name, email, role (admin/staff/client), created_at
- `leads`: id, client_name, phone_number, status (new -> contacted -> closed), created_at
- `ai_logs`: id, user_id FK -> users, prompt_tokens, completion_tokens, model_name, created_at

Lead Pipeline: `[new] -> [contacted] -> [closed]`

RBAC: admin (full), staff (operational), client (limited portal)

**10.6 Why This Stack Wins for MY SMEs**
- Traditional agency: cPanel + MySQL + WordPress = slow, RM500/mo, downtime, no branching.
- Us: Edge + Serverless + Branching = fast, RM0 start, instant preview deployments, zero maintenance.
